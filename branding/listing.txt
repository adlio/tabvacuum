Detailed description (both stores)
Find the tab you need. Put the rest in order.

Aaron's Tab Vacuum—ATV for short—brings tab search, sorting and cleanup together in a keyboard-friendly browser extension.

FIND AND SWITCH
Search open tabs by title or URL across your windows, or limit search to the current window. Results update as you type. Use the arrow keys to choose a tab and Enter to switch to it. Open search with an empty query to see your ten most recently focused tabs.

SORT AND ORGANIZE
Sort tabs in the current window by URL, title, last accessed, most visited, or Frequent & recent, which combines visit frequency and recency. URL and title sorts work in either direction. Pinned tabs stay in place. Merge windows to bring scattered tabs together.

CLOSE WHAT YOU NO LONGER NEED
Close individual results or select several tabs and close the set while keeping search open. Use the row's close button, or press Tab to enter the results, move with arrows or j/k, and press x to close. On-screen hints explain multi-select and the other keyboard controls.

CLEAR THE CLUTTER
Remove duplicate and blank tabs from the toolbar menu or with customizable shortcuts. Stale Tabs opens inline controls so you can choose an inactivity duration, see how many tabs qualify, and review them before selecting Close N tabs now. The existing stale-tab shortcut opens the same controls.

AUTOMATIC STALE-TAB CLEANUP (0.6.0 DRAFT)
Optionally enable hourly automatic cleanup, with seven days as the default. The main menu shows Auto-Close Enabled and, when tabs qualify, the count and next local closing time. Nothing closes immediately when you enable it. Automatic cleanup works in normal windows only and always keeps each window's active tab—regardless of how long since it was active—plus pinned, audio-playing and last-in-window tabs. Tabs are closed, not archived; unsaved changes may be lost. The feature uses the alarms permission without additional website access.

Age tracking: on Firefox a tab's age counts from when you last viewed it; on Chrome it counts from when you last selected (activated) it, so the clock starts when you switch to a tab, not when you leave it. Each window's active tab stays protected even past the threshold. Chrome's native timestamp preserves age across clean restarts; ATV also keeps a small local timestamp-only record to correct known older restored times, with no page addresses, titles, tab IDs or private-window activity and no extra permission. An abrupt crash that loses recent activity in both Chrome and ATV can still make a restored tab appear too old. Tabs with unknown or inconsistent age are kept.

Choose how duplicate URLs are matched and which pinned/audio protections manual cleanup uses in Settings. Explicit toolbar actions show progress and report results through a system notification, subject to your browser and operating-system settings.

LOOK BEYOND OPEN-TAB TITLES
Use Search in to add browsing history or text from loaded web pages. History opens a visited page without deleting its history entry. Page-content search shows matching snippets and requires optional website access that you grant in Settings. Both sources start off each time search opens. Sleeping and restricted pages are skipped; history search is unavailable in private windows.

LOCAL PROCESSING
ATV processes tab information, history matches and page text locally. It does not send your browsing data to the developer or an analytics service. No account is required, and there is no background page-content index.

OPEN SEARCH FROM YOUR KEYBOARD
Mac: Command + Shift + period (.)
Windows and Linux: Ctrl + Shift + period (.)
Existing installations may retain an earlier or custom shortcut. You can change the binding in your browser's extension shortcut settings.

Closing tabs takes effect immediately. You can try your browser's Reopen Closed Tab command to recover a page; unsaved page content may not return.

Closing line (Firefox only)
To change a shortcut, open Firefox's Add-ons Manager, choose the gear menu, then Manage Extension Shortcuts.

Closing line (Chrome only)
To change a shortcut, open Chrome's Extensions page and choose Keyboard shortcuts.
